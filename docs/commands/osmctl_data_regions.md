## osmctl data regions

List regional extracts available from Geofabrik

```
osmctl data regions [search] [flags]
```

### Examples

```
  osmctl data regions
  osmctl data regions turkey
```

### Options

```
  -h, --help   help for regions
```

### Options inherited from parent commands

```
  -o, --output string   output format: text, json, xml, geojson (default "text")
  -s, --server string   OSM instance: dev, osm, or a URL (env OSMCTL_SERVER) (default "osm")
```
