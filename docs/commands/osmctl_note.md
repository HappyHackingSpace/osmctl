## osmctl note

Report problems and resolve map notes

### Synopsis

Map notes are how anyone reports a problem or a missing place without
editing the map directly. Mappers then fix the map and close the note.

### Options

```
  -h, --help   help for note
```

### Options inherited from parent commands

```

  -s, --server string   OSM instance: dev, osm, or a URL (env OSMCTL_SERVER) (default "osm")
```
