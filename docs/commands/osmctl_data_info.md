## osmctl data info

Count elements and show the extent and age of a file

```
osmctl data info <file> [flags]
```

### Examples

```
  osmctl data info turkey-latest.osm.pbf
```

### Options

```
  -h, --help   help for info
```

### Options inherited from parent commands

```
  -o, --output string   output format: text, json, xml, geojson (default "text")
  -s, --server string   OSM instance: dev, osm, or a URL (env OSMCTL_SERVER) (default "osm")
```
